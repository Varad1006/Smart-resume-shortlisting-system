    How ranking works

    1. Read. Each file's embedded text is used where it exists; scans, photos and handwriting go through Chandra OCR (90+ languages), with Tesseract as a fallback.
    2. Retrieve. A multilingual model compares the job with every passage of every resume, so a Hindi or French resume can match an English job description.
    3. Match requirements. A cross-encoder scores each requirement against the most relevant passages and keeps the evidence it found.
    4. Rank. Score = {{ coverage_pct }}% requirement coverage + {{ semantic_pct }}% semantic similarity, plus the optional profile bonus.
